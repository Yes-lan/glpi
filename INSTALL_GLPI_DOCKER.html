Installation détaillée de GLPI avec Docker (Windows)

Guide adapté au dossier: c:\Users\npichon\Desktop\glpi

1) Prérequis

  • Docker Desktop installé et démarré
  • WSL2 activé (recommandé)
  • Port 8080 disponible
docker --version
docker compose version
docker info

2) Démarrage

docker compose pull
docker compose up -d
docker compose ps

Accès GLPI: http://localhost:8080

3) Installation web GLPI

  • Langue → Licence → Installer
  • Serveur DB: mysql
  • Base: glpi
  • Utilisateur: glpi
  • Mot de passe: glpi

4) Sécurité minimale

  • Changer immédiatement les mots de passe par défaut
  • Créer un admin nominatif
  • Épingler les versions d'images en production

5) Sauvegarde

docker compose exec db sh -c "mysqldump -u$MYSQL_USER -p$MYSQL_PASSWORD $MYSQL_DATABASE" > glpi-backup.sql
